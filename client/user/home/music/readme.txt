Put .mp3 files here for ingame music

Drag them onto the file panel and they land in the filesystem like anything
else -- DIR lists them, FILELEN measures them, COPY and DEL work on them.

To hear one:

    MUSIC "play /home/music/theme.mp3"
    MUSIC "loop /home/music/theme.mp3"
    MUSIC "stop"

CAT on one of these does what CAT on a sound file has always done, so do not
be alarmed.
